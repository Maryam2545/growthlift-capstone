# GrowthLift Task Manager

## Project Description

GrowthLift Task Manager is a full-stack MERN application that allows users to securely manage their daily tasks.

## Target User

Students, interns, and professionals who want a simple application for organizing and tracking their tasks.

## Core Features

1. User Registration and Login
2. Create Tasks
3. View Tasks
4. Mark Tasks as Complete or Incomplete
5. Update and Delete Tasks

## Tech Stack

### Frontend
- React
- Vite
- Axios
- React Router
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
